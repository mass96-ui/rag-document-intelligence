# Soleus Knowledge Directory

This directory is reserved for SoleusAI-specific knowledge base documents.

## Purpose

Documents here relate to the SoleusAI system — its device protocols,
integration specifications, and system-specific reference materials.

## Expected Formats

- PDF (clinical protocols, device manuals)
- Markdown (design docs, specifications)
- Plain text (notes, summaries)

## Important

**Real clinical knowledge documents must not be committed to Git.**

This directory is a placeholder. When authoritative documents are available,
they should be placed here and ingested via the standard ingestion pipeline.

Authority: All clinical decisions must be based on doctor-approved material.
