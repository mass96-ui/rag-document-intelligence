# EMG Knowledge Directory

This directory is reserved for EMG (electromyography) and
neuromuscular reference materials.

## Purpose

Documents here cover muscle activation patterns, EMG analysis,
neuromuscular assessment, and related measurement techniques.

## Expected Formats

- PDF (research papers, EMG studies)
- Markdown (reference summaries)
- Plain text (notes)

## Important

**Placeholder content is not authoritative.** Clinical interpretations of
EMG data require physician oversight.

Authority: EMG materials are reference data. Clinical decisions require
physician review.
