# Diabetes Knowledge Directory

This directory is reserved for diabetes management reference materials.

## Purpose

Documents here cover diabetes physiology, glucose monitoring,
insulin management, and diabetic exercise considerations.

## Expected Formats

- PDF (clinical guidelines, ADA standards of care)
- Markdown (reference summaries)
- Plain text (notes)

## Important

**Doctor-approved diabetes management protocols are required for
patient-specific recommendations.** This directory must not contain
authoritative clinical guidelines until they have been reviewed and
approved by a qualified clinician.

Authority: Only clinician-approved materials should inform patient care.
