# Exercise Science Knowledge Directory

This directory is reserved for exercise science reference materials.

## Purpose

Documents here cover exercise physiology, training principles,
muscle activation patterns, and exercise methodology.

## Expected Formats

- PDF (research papers, textbooks)
- Markdown (reference summaries)
- Plain text (notes)

## Important

**Placeholder content is not authoritative.** Clinical exercise
recommendations must be supported by doctor-approved evidence.

Authority: Exercise science materials serve as general reference. Clinical
decisions require physician oversight.
