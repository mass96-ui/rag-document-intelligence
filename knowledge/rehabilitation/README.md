# Rehabilitation Knowledge Directory

This directory is reserved for rehabilitation-specific reference materials.

## Purpose

Documents here cover rehabilitation protocols, recovery guidelines,
and physical therapy reference materials.

## Expected Formats

- PDF (clinical rehabilitation protocols, PT guidelines)
- Markdown (protocol summaries)
- Plain text (reference notes)

## Important

**Doctor-approved rehabilitation protocols are required for any clinical
recommendations.** Placeholder content is not authoritative.

Authority: Only protocols explicitly approved by qualified clinicians should
be used for patient-specific recommendations.
